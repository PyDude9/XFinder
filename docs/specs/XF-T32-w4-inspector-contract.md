# XF-T32 W4 Inspector — owner-authorized continuation, 2026-10-27

Implements Q-T32-6 from XF-T32-tilde-direction. Keep existing preview toggle and facts/tags. Add Info/Preview tabs, Open/Reveal/Copy Path/Share, bounded Markdown and code previews, and image conversion/resize/flip through a short-lived `XFinder --image` child. No new third-party module. Source files are never overwritten. ImageIO-supported targets only; WebP has an explicit unavailable explanation if no encoder is advertised.

Steps (one agent branch, separate commits):
1. Preview refresh and content: selected-entry revision key (path, inode, size, modified plus listing delivery revision), nanosecond stat identity cache key, cancellation/generation checks, fail-safe thumbnail and video teardown, Info/Preview navigation, bounded UTF-8 text with Markdown AttributedString and lightweight lexical highlighting; actions.
2. Pure image request/identity/output rules plus child worker and UI. Child dispatch before app scenes. Parent never decodes pixels, no in-process fallback. Child revalidates source identity, cloud/local status and input limits. Encoded bytes create a new file with exclusive creation; collision retries. Resize and flip always create PNG copies; conversion offers PNG/JPEG only when encoders exist (WebP too if available). Resize presets shrink only, flips apply EXIF orientation. First frame only, explained in UI. Parent allows one job, cancellable on selection change/disappear, 60s deadline and child exit cleanup; output shown without changing a newer selection.

Failure cases: empty/multiple selection clears; unreadable/disappeared file gives explanation; cloud-only/dataless never read or downloaded; oversized/binary/non-UTF8 text gives explanation, max 256 KiB read; bounded rendering; stale selection/load/thumbnail cannot replace newer content; watcher refresh re-renders selected changed file; no automatic video play and player paused/detached on teardown. Unsupported encoder gets explanation; corrupt/huge image fails safely in child; source replaced mid-action rejected; no overwrite even if destination appears during action; no output directory permission displays localized failure; cancel/timeout terminates worker and no fallback in UI process. Metadata/progress when controls hidden does no work; preview off removes view and stops work. No new preference switches.

Files: PreviewPaneView.swift; BrowserWindowModel.swift (listing revision only); new InspectorPreviewRules.swift (Foundation, test symlink); new InspectorImageRules.swift and InspectorImageChild.swift (4 pbx entries each, pure rules test symlink); new InspectorImageActions.swift (4 pbx entries); XFinderApp.swift (early child dispatch); L10n add-only script/store; tests and worklog.
